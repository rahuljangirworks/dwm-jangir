# LightDM background sources

The VM background set was selected by Rahul from the `quattro` branch of
[`omacom/omarchy`](https://github.com/omacom/omarchy). The bundled copies are
2560x1440 WebP files so the greeter decodes only one low-memory image per
login screen.
