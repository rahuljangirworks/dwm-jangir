# LightDM UI assets

- `dwm.svg` - DWM logo derived from
  <https://commons.wikimedia.org/wiki/File:Dwm.svg>, public domain. The stroke
  is recoloured for contrast on the dark greeter session selector.
- `kde.svg` - KDE logo from
  <https://kde.org/stuff/clipart/logo/kde-logo-white-gray-source.svg>, bundled
  for the KDE session row.
- `gnome.svg` - GNOME session artwork supplied from the local Downloads asset,
  bundled for the GNOME session row.
